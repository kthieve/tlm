## Goal
Transform `tlm` into a multi-agent orchestrator that can self-extend and share capabilities.

## Key Features
- **The Agent Quad**:
  - Roles: Orchestrator, Advisor, Subagent, and Architect.
  - The **Architect** builds new Abilities/Extensions.
  - The **Governor** audits Architect changes and validates builds against strict safety policies.
- **Proactive Self-Improvement**:
  - The Autonomous **Heart** (from v0.6.0) can proactively identify workflow bottlenecks or missing features.
  - Without being explicitly asked, the Heart can queue a task for the **Architect** to design a new tool or blueprint to solve the problem.
  - The **Governor** ensures these autonomous self-improvements are staged safely in containment (v0.4.0) and require user approval before integration.
- **Blueprints & Modules**:
  - Standardized format for shareable capabilities.
  - Portability: Export/Import blueprints as single files.
- **Background Workers**:
  - Daemonized tasks with virtual tool-call heartbeats.
  - Persistent state management for long-running jobs.

## Success Criteria
- [ ] The Architect successfully implements a requested "Ability" autonomously.
- [ ] A Blueprint exported from one machine works perfectly on another.
- [ ] Background workers survive a terminal disconnect and report status via heartbeat.
- [ ] The Governor successfully blocks a non-compliant Architect change.
- [ ] Agent Quad collaboration reduces task time by > 20% vs single-agent approach.
