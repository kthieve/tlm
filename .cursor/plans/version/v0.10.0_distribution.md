# Milestone 0.10.0: Distribution (Enterprise & Packaging)

## Goal
Ensure `tlm` is stable for global production use, properly packaged for all major platforms, and integrated with system security.

## Key Features
- **Global Distribution**:
  - Official packages for **Homebrew** (macOS/Linux), **AUR** (Arch), **Scoop**, and **Winget** (Windows).
  - Automated CI pipelines for `.deb` and `.rpm` generation.
- **Enterprise Safety**:
  - **Strict Allowlists**: Production-ready profiles that block all non-whitelisted execution.
  - **Audit Logging**: Immutable, signed log of all system-modifying actions.
- **Secrets Management**:
  - Native system keyring integration (Secret Service, Keychain, Windows Credential Manager).
- **Self-Update**:
  - **`tlm self-update`**: Secure binary and Ability-environment updates.
- **Verified Blueprint Registry**:
  - **Cryptographically Signed Blueprints**: To prevent "Hive" malware risks, all shared blueprints must be signed by a trusted authority or local team-lead key.
  - **Audit & Review**: Import interface in the WebUI shows a full audit of what a Blueprint will do before activation.
  - **Local-Only Hive**: Support for secure, P2P blueprint discovery within a local network using signed certificates.

## Success Criteria
- [ ] `tlm` is installable via a single command on all four major package managers.
- [ ] Secrets are securely read from the system keyring without being stored in plaintext.
- [ ] Self-update correctly migrates all internal Ability environments and RAG databases.
