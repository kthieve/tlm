## Goal
Establish a robust, multi-tiered persistence layer for all `tlm` operations, including comprehensive memory management and resilient background worker state recovery. This milestone also seeds the "Foundation of the Heart."

## Key Features

### 1. Advanced Multi-Tiered Memory
A highly functional state management system designed for accuracy and token economy:
- **Instant Memory (Live Context)**: High-frequency management of the immediate token window.
- **Short-Term Memory (Session/Worker State)**:
  - Tracks active worker plans and conversation threads.
  - **Context Compact**: Continuous background summarization of older session parts.
- **Long-Term Memory (The Digital Twin)**:
  - **Embedded RAG & Graph**: Beyond text search, it maps causal relationships (e.g., "This function was changed because of that bug log last Tuesday").
  - **Deduplication & Reinforcement**: Semantically merges repetitive facts; reinforces frequently accessed knowledge.
  - **Categorization & Forgetting**: Strict tagging (`[user_pref]`, `[code_base]`) and importance-based time-decay.

### 2. Modular Sensory System (The Nerves)
- **Multi-Modal Sensing**:
  - **System Metrics**: Monitors CPU load, disk space, and memory usage.
  - **Environment Awareness**: A plugin architecture for external sensors (e.g., room temperature, ambient light).
  - **Hardware Safety**: Pauses autonomous background work if system metrics indicate stress.
- **Resilient Worker & Subagent State**:
  - **Full Serialization**: Workers save their entire execution stack and plan to encrypted `.tlm/workers/` files.
  - **Snapshot Integration**: State recovery is integrated with **Temporal Snapshotting (v0.3.0)**, ensuring a resumed worker always starts from a consistent filesystem state.
  - **30-Second Checkpoints**: Automated snapshots for resilient recovery.

### 3. The Heart's Foundation (The Silent Watcher)
The initial, passive phase of the Heart daemon:
- **Thought Logging**: The Heart begins its internal monologue, recording observations and "reflections" in `.tlm/heart/thoughts.log`.
- **Passive Personality Learning**: Starts building the user profile by observing interaction tone and style without driving the conversation yet.
- **The Glimpse (Sensing Layer)**: Tier 3 model-based sensing of high-signal system events to update its thought logs.

## Success Criteria
- [ ] RAG accurately retrieves a project-specific fact across separate sessions.

- [ ] The Heart generates a consistent, accurate `thoughts.log` summarizing daily user interactions.
- [ ] 30-second checkpoints incur < 100ms latency overhead.
- [ ] Memory deduplication correctly identifies and merges 90% of redundant facts.
