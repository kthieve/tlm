# Milestone 0.3.0: Foundation (Safety & Streams)

## Goal
Establish the core security and interaction patterns required for all future "agentic" capabilities.

## Key Features
- **Four-Tier Permission Model**:
  - **Root (Tier 0)**: High-risk system operations requiring `tlm auth` (maps to an enhanced `trusted` profile).
  - **Workspace (Tier 1)**: Full access within project root (maps to `standard` profile).
  - **Whitelist (Tier 2)**: Restricted to `permissions.toml` (maps to `strict` profile).
  - **Sandbox (Tier 3)**: Isolated `bwrap`/`firejail` execution (new profile).
- **Execution Safety**:
  - **Temporal Snapshotting (The Agent Undo)**: Before any Tier 1/2 "Workspace" change, the system takes a lightweight snapshot.
  - **Perfect Rollback**: Revert the entire workspace to the last known good state via `tlm undo`.
  - **Security & Recovery Foundation**:
    - **Password Access**: Optional password protection for sensitive operations (Tier 0/1) and configuration edits.
    - **Recovery System**: Local-only "Master Recovery Key" generated during `tlm init` to regain access if the password is lost.
  - **Atomic Transactions**: Multi-file writes must be staged in `.tlm/tmp` and moved atomically.
- **Interactive Control**:
  - Graceful SIGINT (Ctrl+C) handling for LLM streams and shell executions.
  - `tlm stop`: Hard-kill runaway processes and clean up temporary stages.

## Success Criteria
- [x] SIGINT stops any running model or process without leaving side effects.
- [x] Root operations are blocked unless `tlm auth` is active.
- [x] All CLI subcommands support a standard `--dry-run` flag.
