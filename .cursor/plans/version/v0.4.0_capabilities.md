## Goal

Enable `tlm` to grow its own tools and manage their dependencies through a non-destructive plugin architecture ("Abilities").

## Key Features

- **Plugin Hook System**: Non-destructive `src/` hooks for extending `tlm`.
- **Integrated Abilities**: Framework to download, build, and link executables from source.
- **Language-Specific Containment**: Isolated `venv` (Python) and `node_modules` (Node.js) for every Ability.
- **`tlm ability` CLI**: Management tools for lifecycle control (list, install, test, uninstall).

## Success Criteria
