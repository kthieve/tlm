# Milestone 0.4.0: Capabilities (Abilities & Containment)

## Goal
Enable `tlm` to grow its own tools and manage their dependencies through a non-destructive plugin architecture.

## Key Features
- **Integrated Abilities (Source-Built)**:
  - Framework to download, build, and link executables from source (e.g., Lightpanda).
- **Language-Specific Containment**:
  - **Python**: Automated `venv` management per Ability.
  - **Node.js**: Isolated `node_modules`.
  - **Compiled**: Sandbox build staging.
- **Ability Extensions**:
  - Hook-based system to modify core `tlm` behavior without changing `src/`.
- **`tlm ability list/install/test`**:
  - CLI management tools for lifecycle control.

## Success Criteria
- [ ] A new Python Ability can be installed and run without contaminating the global environment.
- [ ] `tlm` can compile a simple tool from source and make it available as a subcommand.
- [ ] Core logic remains untouched when an Extension is active.
