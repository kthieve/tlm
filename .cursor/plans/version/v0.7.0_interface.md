## Goal
Provide high-level visibility into the system state, background workers, and agent "thinking" processes through a lightweight local web interface.

## Key Features
- **Lightweight Embedded WebUI**:
  - Embedded local server (FastAPI/Flask) for visual chat, history, and settings management.
  - **Local Authentication**: Token-based login for secure local/network access.
- **Unified Configuration Hub**:
  - All features, tiers, and settings are parity-accessible via **TUI, WebUI, and GUI**.
  - Real-time settings synchronization: Changes made in the WebUI are instantly reflected in the TUI/GUI and vice-versa.
- **Sentient Self-Configuration**:
  - **Natural Language Setup**: Use `tlm` to help configure itself. (e.g., *"tlm, increase my daily budget to $5 and set the safety tier to Workspace"*).
  - **Guided Wizard**: The agent can proactively suggest setting changes based on current project needs (e.g., *"I noticed you are using Node.js, would you like me to enable Node containment for your Abilities?"*).
- **The Observation Deck**:
  - **"Thinking" Stream**: Real-time visual log of agent reasoning, tool-selection logic, and planning.
  - **Worker/Subagent Live-Map**: Graphical view of active background tasks, progress bars, and status.
  - **Heartbeat Diagnostics**: Visual "pulse" showing the health of the Heart's Foundation and nanobot signal logs.
- **Emergency Controls**:
  - Centralized "Stop All" button to instantly halt all background and foreground executions.
- **Resource Monitoring**:
  - Dashboard for real-time tracking of token usage and costs across all tiers.

## Success Criteria
- [ ] WebUI starts instantly and displays real-time "thinking" logs from a CLI session.
- [ ] Emergency stop successfully terminates all active subprocesses and background workers.
- [ ] Usage dashboard correctly reflects cost data from the telemetry layer.
- [ ] Self-configuration correctly updates `config.toml` from natural language.
- [ ] Observation Deck live-map shows subagent dependencies correctly.
