## Key Features

### 1. The Personality Engine
- **Persistent Persona**: The Heart's learned observations are distilled into a stateful `personality.json` file.
- **Human-Like Interaction**: This persona drives the "voice" of TLM, adjusting tone, brevity, and focus based on its deep understanding of the user.
- **Conversation Driver**: Standard `tlm ask` sessions are now preceded by the Heart's recent "thoughts" and persona injection.

### 2. Proactive Autonomy & Command
- **Self-Directed Logic**: The Heart proactively identifies gaps in knowledge or workflow.
- **Ghost Mode (Speculative Pre-Computation)**:
  - While the user is away, the Heart uses idle time to "ghost-run" the next logical steps in a plan within a strictly sandboxed environment.
  - When the user returns, the Heart presents pre-calculated results and diffs for approval, saving significant time.
- **Synthetic Self-Correction**:
  - After a user manually corrects an agent's mistake, the Heart performs a "Post-Mortem" analysis.
  - It creates a **"Synthetic Lesson"** in long-term memory, ensuring the system learns from its own failures and never repeats the same mistake.
- **Knowledge Proxy**: Pre-fetches documentation or researches solutions in the background.

### 3. Social Bridges & Remote Heart
- **Discord & Telegram Integration**: Allows the Heart to speak asynchronously to the user, providing "thoughts" or asking clarifying questions while the user is away from the terminal.
- **Remote Control**: Command the Heart or Subagents via social chat (guarded by the Four-Tier Permission Model).

### 4. Smart Reflection & Token Guard
- **Hierarchical Reflection**: Uses "Glimpse" triage and tiered models to ensure the Heart's sentience stays within a strict token budget.
- **Global Reflection Cap**: Daily hard-stop on autonomous background tasks to prevent cost overruns.

## Success Criteria
- [ ] The Heart successfully prompts the user via a Social Bridge with a proactive suggestion.

- [ ] The Heart autonomously commands a subagent to perform a maintenance task that the user later approves.
- [ ] Synthetic lessons correctly prevent a repeated mistake in a test suite.
- [ ] Ghost mode correctly predicts the next 3 steps in a standard project setup.
- [ ] Daily token budget for background tasks is never exceeded by the Heart.
