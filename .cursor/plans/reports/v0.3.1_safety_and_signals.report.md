# Agile Report: v0.3.1 - Safety Tiers & Interactive Control

## Summary
Successfully implemented the foundational Four-Tier Permission Model, robust SIGINT handling, and Modular Tool Wrappers.

## Changes

### 1. Four-Tier Permission Model
- Formalized `SafetyTier` IntEnum (ROOT=0, WORKSPACE=1, WHITELIST=2, SANDBOX=3).
- Updated `SafetyProfile` to map to these Tiers.
- Enhanced `overlay_effective_policy` to enforce Tier-specific constraints (e.g., Sandbox forces network OFF and engine AUTO).

### 2. Interactive Control (SIGINT)
- Implemented global `KeyboardInterrupt` handling in `cli.py`.
- Added robust process group termination in `modes/do.py` using `os.killpg` and `start_new_session=True`.
- Ensured tool loops in `ask_tools.py` stop gracefully on interrupt.

### 3. Modular Tool Wrappers
- Created a new extensible architecture for system tools under `src/tlm/safety/tools/`.
- Implemented specialized wrappers for `git` and generic package managers.
- Migrated read-only check logic from core profiles into the modular registry.
- Integrated granular tool validation into the `tlm do` execution loop.

### 4. Dry Run Consistency
- Added `--dry-run` support to `tlm allow` and `tlm unallow` subcommands.

## QC Findings
- **Safety**: Four-tier model correctly isolates high-risk operations.
- **Signals**: Verified that `Ctrl+C` terminates both LLM streams and shell process groups.
- **Modularity**: System tools are now easily configurable via dedicated Python scripts.
